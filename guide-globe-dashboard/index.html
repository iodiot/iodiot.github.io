01

From a public feed to a reliable event record

The dashboard loads real USGS GeoJSON, normalizes it into a small typed model, then merges updates by event ID.

Fetch30-day M2.5+ feed
ParseNormalize GeoJSON
MergeRefresh by ID
SelectFilter + derive
RenderAll views stay in sync

Start with the month feed

On load, the app requests the public M2.5+ GeoJSON feed for the past 30 days. It needs no API key and supports browser requests from the demo.

Normalize once at the edge

The parser drops malformed records, rounds magnitude to one decimal place, extracts a region, converts tsunami flags and keeps coordinates, depth, felt reports, significance and alert level in a typed event.

Refresh only the recent window

Every five minutes, a smaller 24-hour feed is fetched and merged by event ID. Newer records replace older copies; the resulting array stays sorted newest first.

Derive views from shared state

Range, minimum magnitude, region query, sorting, selection and playback cursor live in one Zustand store. Memoized selectors calculate the visible records and summaries.

Update the dashboard as one system

The globe, virtualized list, KPI cards, timeline and magnitude histogram read the same derived event set, so selecting or scrubbing does not leave a panel behind.

Resilient loading

Live feed first, labelled snapshot if needed

If the network or USGS is unavailable, the app loads a bundled snapshot instead. The dashboard labels the data as a snapshot and shows a banner so the fallback is visible to the reader.

IDIdentity and time

USGS event ID and timestamp support stable merging and newest-first ordering.

⌖Place and depth

Longitude, latitude, depth, place and normalized region position the event on the globe and support search.

MMagnitude and impact

Magnitude, significance, tsunami flag, felt reports, alert level and magnitude type power the details and summaries.

02

From one GeoJSON row to dashboard numbers

Follow an actual snapshot event through normalization, filtering and the calculations used by the dashboard cards and charts.

Input · USGS GeoJSON

{
  "id": "us6000u3fy",
  "geometry": { "coordinates": [-103.289, 31.978, 5.4] },
  "properties": {
    "mag": 2.7,
    "place": "17 km SSW of Jal, New Mexico",
    "sig": 112, "tsunami": 0, "felt": null
  }
}
How the parser turns that row into a typed event
coordinateslon −103.289°, lat 31.978°, depth 5.4 km (GeoJSON order is longitude, latitude, depth)
mag 2.7Rounded to one decimal place; stored as 2.7
placeKept for display and search; the final comma-separated part gives region “New Mexico”
sig / tsunami / felt112 / false / 0 — null felt reports become zero, and tsunami is true only when the source flag is 1

03

One source of truth, several synchronized views

Each panel subscribes to the part of the dashboard state it needs. Memoized selectors prevent repeated filtering work when multiple panels read the same results.

Small subscriptions

Components select only the state they need. Expensive derived arrays are memoized by input identity, so the same filter result can serve several panels without recomputing it for each one.

04

Put every event in its place on Earth

The 3D scene turns longitude and latitude into globe positions. Instancing keeps marker rendering compact as the event set changes.

Three.js / React Three Fiber

One instanced mesh for the visible events

Each event becomes a low-poly sphere positioned by latitude and longitude. Magnitude sets marker size and colour; selection and hover add emphasis. All markers share one InstancedMesh draw call.

Recent-event pulse rings are animated in a vertex shader. Clicking a marker selects that event and eases the globe camera toward it; markers on the far side are occluded for picking.

  • Blue Marble texture
  • Fresnel atmosphere
  • Shader pulses
  • Quaternion camera flight

Search and share

Make a dashboard view portable

Region search is debounced and supports region suggestions; the event list can be sorted by latest or strongest. The URL stores the selected range, minimum magnitude, search query, sort and selected event, so the Share action can reproduce a useful view.

?range=30d&mag=4.5
&q=Japan&sel=us6000…
RThree time ranges

24 hours, seven days and thirty days set the time window used for event filtering and chart buckets.

MMagnitude threshold

The slider sets the minimum magnitude; clicking a magnitude-chart bar can set that threshold too.

QRegion query

Search filters place names and regions, with chips for the most active regions in the current window.

06

Make the dashboard usable when the feed is not

Data clarity, keyboard access and reduced motion are part of the interface, not afterthoughts.

!Honest fallback

A bundled offline snapshot is marked clearly when the live USGS request cannot be completed.

⌨Keyboard support

The event list is an accessible listbox. Arrow keys, Home, End and Page Up / Page Down move through events.

◐Comfortable motion

Dark and light themes are supported. Reduced-motion preferences turn off auto-rotation, marker pulses and camera flights.

Keyboard shortcuts

  • / — focus region search
  • Space — play or pause the timeline
  • Esc — clear the current selection
  • T — change the theme

Data and imagery

Public feeds, public-domain textures

Earthquake locations and event metadata come from the USGS Earthquake Hazards Program real-time GeoJSON feeds. The Earth texture is NASA Blue Marble imagery; the bundled snapshot is used only as an offline fallback.
