01 Featured demos

Things you can try right now. Familiar Local is a free Mac app you download; everything else runs live in the browser. Dungeon Dash works anywhere, phones included, the globe and bubbles.js run on WebGL, and the crowd and ocean demos need a WebGPU-capable browser (recent Chrome or Edge).

Familiar Local 2026

A private little chat app for your Mac that talks to Apple’s on-device Foundation Models, so nothing you type ever leaves the computer. A small Swift server listens only on 127.0.0.1 and serves a clean web chat, which opens in its own native window or in any browser. Keep separate conversations, each with its own memory, flip between light and dark themes, and grab a ready-made macOS app straight from the repo.

Dungeon Dash (prototype)

Mobile-first 3D dungeon runner in the browser, built with TypeScript and Three.js. WebGPU with a WebGL2 fallback, so it runs in any modern browser, including phones. A deterministic fixed-timestep simulation stays separate from rendering, with async echo ghost runs. About 213 KB gzip on the initial load.

webgpu-crowd

Crowd simulation running entirely on the GPU: boids flocking in WebGPU compute shaders (WGSL), with a spatial hash grid for neighbour lookups. Scales from 1k to 100k agents in real time, with live controls.

  • WebGPU

webgpu-ocean

A living ocean in your browser, built on Three.js and WebGPU. Every wave is simulated on the GPU in real time, from long 250 m swells down to ripples a few centimetres across. Crests sharpen and break into foam, the water mirrors the sky, sparkles in the sun and glows where light shines through thin waves. Pick the weather: Calm, Breeze or Storm.

  • Three.js
  • WebGPURenderer
  • TSL compute
  • FFT
  • TypeScript
Live demo Code

globe-dashboard

Live earthquake dashboard built around a 3D globe, streaming the USGS real-time feed. Every event is drawn as one instanced marker, and recent events pulse in a shader. Hover or click an event to fly the camera to it. The virtualised event list, filters, KPI cards and SVG charts all stay in sync with the globe. Timeline playback, shareable URL state, dark and light themes, a responsive layout and full keyboard navigation. Falls back to a labelled snapshot when the feed is unreachable.

  • React
  • TypeScript
  • Three.js / R3F
  • zustand
  • Vite
  • Vitest

bubbles.js 2021

Thousands of iridescent soap bubbles on the GPU in Three.js: a GPGPU curl-noise simulation drawn in one instanced call, with ray-traced spheres, spectral thin-film interference and HDR reflections. Blow on them or pop them.

GpuFluid 2014 · refreshed 2026

C++ / OpenGL fluid solver on the GPU: advection, buoyancy and a Jacobi pressure solve as shader passes. Refreshed in 2026 with coloured dye, vorticity confinement, a 512 grid and a cross-platform CMake + GLFW build.

  • C++

GpuRayTracer 2015 · refreshed 2026

Shiny metal spheres on an endless checkerboard, ray traced live on the GPU, with every pixel worked out in a single C++ / OpenGL shader. Light bounces twice between the spheres, shadows fall soft from an area light and the lighting slowly shifts as you watch. Refreshed in 2026 with a new look and a cross-platform CMake build.

  • C++
  • OpenGL
  • GLSL
  • Ray tracing

GpuVoxels 2015 · refreshed 2026

A little blocky island in autumn colours, ray cast live on the GPU from a 64×64×64 grid of voxels stored as an OpenGL 3D texture. Every pixel walks through the grid block by block until it hits the ground, a tree or the winding river, while a ball drifts over the treetops. Written in C++ and GLSL, and refreshed in 2026 with a new scene.
