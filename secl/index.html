Interactive Globe Dashboard

Exploring real-time geospatial data through an interactive 3D globe and a fully integrated React dashboard.

Live Demo↗GitHub↗

The application fetches real-time earthquake data from USGS in GeoJSON format and visualizes events at their geographic locations.
